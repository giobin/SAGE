# gym_cards Environments

This release includes the `EZPoints-v0` and `CardMaze-v0` environments used in
the main SAGE experiments. The environments are registered under:

```python
gym.make("gym_cards/EZPoints-v0")
gym.make("gym_cards/CardMaze-v0")
```

The card image assets and base environment structure are adapted from the
RL4VLM environment code released under the MIT License.
